# P7-10 Capital Reallocation Readiness

This boundary identifies why Atlas cannot yet create a capital-reallocation
proposal. It does not choose a portfolio allocation.

The current public operational chain has no private portfolio scope, no live
canonical incumbent-position amounts, no executable P8-13 challenger, no
authorized Harvest proceeds, and no ratified risk-budget or allocation-ranking
authority. Each missing axis is reported separately.

The fixed output is action `NONE`, capital `0`, null maintain/reduce/add/probe
amounts, null expected proceeds, null reallocation/trade/order proposals and
all authority false. The P7-11 packet is semantically rebuilt from its exact
P8-13 and historical-audit inputs before use.
