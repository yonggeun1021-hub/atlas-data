# P8-10 Price State Operational Evidence Inventory

This inventory independently revalidates the retained Dynamic Clock sources
behind Candidate Validity observations and measures whether real operational
candidates carried a linked Price State diagnostic.

Natural and manual samples are separated and deduplicated by the
evaluation-invariant source hash. Price State remains diagnostic-only under
PROVISIONAL classification thresholds. Reflection Status remains structurally
UNKNOWN, and the inventory cannot evaluate candidate validity, open Risk
Capacity, start P8-13, size a position, or create a money action.
